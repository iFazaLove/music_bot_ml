# Music Bot ML

Учебный Telegram-бот для загрузки и каталогизации музыки. Первая версия сохраняет
метаданные трека и Telegram `file_id`, не занимая место постоянными аудиофайлами.

## Что реализовано

- регистрация пользователя по `/start`;
- загрузка аудио из Telegram;
- временное скачивание и чтение тегов через Mutagen;
- ручной ввод названия и исполнителя, если метаданные отсутствуют;
- хранение пользователей и треков в SQLite;
- личная библиотека пользователя по команде `/my`;
- поиск по названию и исполнителю через `/search запрос`;
- повторная отправка найденного трека по Telegram `file_id`;
- лайк и снятие лайка кнопкой в библиотеке и результатах поиска;
- добавление найденного трека в личную библиотеку кнопкой `➕`;
- базовые рекомендации по исполнителям, популярности и случайному порядку;
- обнаружение точных дубликатов по SHA-256 содержимого аудиофайла;
- хранение Telegram `file_id` и `file_unique_id` для повторной выдачи;
- удаление временного файла сразу после обработки.

Лайки сохраняются как пользовательские предпочтения для базовых рекомендаций.

## Технологии

- Python 3.12+
- aiogram 3
- SQLAlchemy и SQLite
- Mutagen
- pydantic-settings
- pytest

## Запуск на macOS

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
cp .env.example .env
python -m music_bot
```

Перед запуском замени значение `MUSIC_BOT_TOKEN` в `.env` на токен своего бота.

## Запуск на Windows

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
python -m music_bot
```

## Демонстрационный сценарий

1. Пользователь отправляет `/start`.
2. Бот предлагает загрузить аудиофайл.
3. Пользователь отправляет один трек.
4. Бот извлекает доступные теги и сохраняет метаданные с Telegram `file_id`.
5. Если название или исполнитель отсутствуют, бот запрашивает их текстом.
6. Повторная отправка того же файла не создаёт дубликат, даже если Telegram выдал новый
   `file_unique_id`.
7. Пользователь открывает `/my` или выполняет `/search исполнитель` и нажимает на трек.
8. Бот отправляет сохранённое аудио по Telegram `file_id`.
9. Пользователь нажимает `🤍`, чтобы поставить лайк, или `❤️`, чтобы снять его.
10. `/recommend` предлагает до пяти новых треков, которых ещё нет в личной библиотеке.
11. Кнопка `➕` добавляет найденный или рекомендованный трек в библиотеку.

## Структура

```text
music_bot/
├── handlers/       # Telegram-команды и диалог загрузки
├── services/       # обработка аудио и метаданных
├── config.py       # переменные окружения
├── database.py     # подключение к SQLite
├── models.py       # таблицы SQLAlchemy
├── repositories.py # операции сохранения и чтения данных
└── main.py         # запуск бота
tests/              # минимальные тесты важной логики
```

Аудиофайлы не добавляются в Git. На будущем ML-этапе их можно будет скачивать
в локальный кэш на отдельном Windows-компьютере.

SHA-256 сравнивает точные байты файла. Обычное переименование файла не меняет хэш,
но изменение встроенных тегов, обложки или кодека создаст другой хэш. Поиск одной и
той же записи в разных файлах можно позже добавить через аудиофингерпринтинг.

Таблица лайков постепенно накапливает реальные взаимодействия пользователей. Для
демонстрации рекомендательных алгоритмов с большим числом пользователей позже можно
создать отдельную demo-базу, не смешивая искусственные данные с рабочими.
